# Project conventions

Pages in this project follow the structure established by `about.html`:

- one `<header>` containing the page `<h1>` and the site `<nav>`
- content inside `<main>`, grouped in `<section>` elements introduced by an `<h2>`
- one `<footer>` with the copyright line
- styles live in `assets/styles.css` : pages carry no inline styles
- titles read `Page — Northwind Bakery`
