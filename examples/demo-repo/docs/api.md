# `demo.money` public API

Every public function in `demo.money` is listed here. Add a row when you add one.

| Function | Description |
|---|---|
| `round_money(amount)` | Reduce a monetary amount to 2 decimal places. |
| `format_currency(amount)` | Format an amount for display, e.g. `$1,234.50`. |
| `parse_amount(text)` | Parse a display string back into a number. |
| `sum_line_items(items)` | Total a list of line items, reduced to 2 decimal places. |
